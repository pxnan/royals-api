🤖 API Chatbot Royal's Resto

Dokumentasi lengkap API untuk Chatbot Royal's Resto.

🔗 Base URL Development: http://localhost:5000
🔗 Base URL Production: https://royals-resto-bot-api.vercel.app
📌 Catatan Penting Autentikasi:
  • API Key (X-API-Key) Wajib (kecuali debug) — Hampir semua endpoint memerlukan API Key, kecuali beberapa endpoint debug (/health, /cek-csv, /fix-csv, /debug-db, /test-db, /debug-headers).
  • Bearer Token (JWT) — Endpoint yang mengelola admin, melihat profil, logout, change password, login logs, reset database memerlukan token JWT (didapat dari /login).
  • Role super_admin dapat mengelola semua admin dan melihat login logs; admin hanya dapat mengelola profil sendiri.
  • Di environment development, validasi API Key dilewati (otomatis dianggap valid).
  • Jangan pernah menyimpan kredensial asli di kode frontend. API Key dikonfigurasi di server.

🔐 Autentikasi & Otorisasi

API Key (X-API-Key)

Hampir semua endpoint mewajibkan X-API-Key di header. Nilai API Key dikonfigurasi di server (tidak ditampilkan di dokumentasi). Untuk development, header ini tidak diperiksa.

JWT Token (Bearer)

Beberapa endpoint yang membutuhkan hak akses admin memerlukan token JWT yang didapat dari /login. Kirim token di header: Authorization: Bearer <token>.

1. Login Admin (butuh API Key)

POST /login Requires API Key

Headers: X-API-Key: your-api-key

Request Body:

{
    "username": "admin",
    "password": "your_password"
}

Response Sukses (200):

{
    "authenticated": true,
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "admin": {
        "id": 1,
        "username": "admin",
        "email": "admin@royalsresto.com",
        "full_name": "Administrator",
        "role": "super_admin"
    },
    "expires_in": 86400
}

2. Logout (butuh API Key + Token)

POST /logout API Key + Bearer Token

3. Verifikasi Token (butuh API Key)

GET /verify-token Requires API Key

4. Ganti Password (butuh API Key + Token)

POST /change-password API Key + Bearer Token

5. Profil Admin yang Login (butuh API Key + Token)

GET /admin-profile API Key + Bearer Token

6. Registrasi Admin Baru (butuh API Key)

POST /api/register Requires API Key

💬 Chatbot

1. Kirim Pertanyaan (butuh API Key)

POST /chat Requires API Key

Headers: X-API-Key: your-api-key

Request Body: {"pertanyaan": "Apa menu favorit?"}

Response (sukses):

{
    "pertanyaan": "Apa menu favorit?",
    "jawaban": "Menu favorit kami adalah Nasi Goreng Royale...",
    "status": "ok",
    "kategori": "menu"
}

Response (ambigu):

{
    "pertanyaan": "resto",
    "opsi_pertanyaan": ["Apa jam buka?", "Dimana lokasi?"],
    "jawaban": "Pertanyaan mana yang kamu maksud?",
    "status": "ambigu"
}

Response (tidak dikenal):

{
    "pertanyaan": "...",
    "jawaban": "Mohon maaf, saya belum mengerti pertanyaan Anda.",
    "status": "unknown"
}

2. Pertanyaan Ambigu - "Tidak Ada" (butuh API Key) NEW!

POST /chat/ambiguous-unknown Requires API Key

Endpoint ini digunakan ketika user memilih opsi "Pertanyaan yang saya maksud tidak ada" pada respons ambigu. Pertanyaan asli user akan disimpan ke tabel pertanyaan_unknow untuk pembelajaran model di masa depan.

Request Body:

{
    "original_question": "Saya mau pesan apa ya?"
}

Response Sukses (200):

{
    "status": "unknown",
    "jawaban": "Mohon maaf, saya belum mengerti pertanyaan Anda. Pertanyaan Anda telah saya catat untuk pembelajaran ke depannya.",
    "original_question": "Saya mau pesan apa ya?"
}

3. Rekomendasi Pertanyaan Random (butuh API Key)

GET /api/recommendations Requires API Key

4. Rekomendasi Berdasarkan Kategori (butuh API Key)

GET /api/recommendations/by-category?kategori=menu Requires API Key

👥 Admin Management (Super Admin Only)

Semua endpoint di bawah ini membutuhkan API Key + Bearer Token dengan role super_admin.

1. Daftar Semua Admin (pagination & search)

GET /api/admins?page=1&per_page=10&search=... API Key + Token (super_admin)

2. Tambah Admin Baru

POST /api/admins API Key + Token (super_admin)

3. Update Admin

PUT /api/admins/{admin_id} API Key + Token (super_admin)

4. Reset Password Admin

POST /api/admins/{admin_id}/reset-password API Key + Token (super_admin)

5. Hapus Admin

DELETE /api/admins/{admin_id} API Key + Token (super_admin)

📊 Manajemen Dataset (Pertanyaan & Jawaban)

Semua endpoint dataset memerlukan API Key (tidak perlu token JWT).

1. Ambil Semua Data (pagination, filter, search)

GET /get-all-data?page=1&per_page=20&search=menu&kategori=harga Requires API Key

6. Ambil Data Berdasarkan Index
